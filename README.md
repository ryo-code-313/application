# ミュウツー厳選チェッカー

ポケモンスリープのミュウツー(スキル型)向けの厳選チェッカーです。選んだサブスキル・性格から、1日あたりの期待スキル発動回数を計算し、無補正個体との比較や全パターン中の順位を表示します。

## 公開ページ

https://ryo-code-313.github.io/application/

## 構成

- `index.html` — マークアップ
- `css/style.css` — スタイル
- `js/constants.js` — サブスキル・性格などのゲームデータ
- `js/calc.js` — 期待値計算エンジン(DOM非依存)
- `js/worker.js` — 上位%の分布計算をバックグラウンドで実行するWeb Worker
- `js/format.js` — 表示用フォーマット関数
- `js/state.js` — アプリ状態管理・localStorage永続化
- `js/ui.js` — DOM描画・イベント処理
- `js/main.js` — エントリーポイント

## 計算モデル

「1日の期待発動回数」を、無補正個体（サブスキルなし・無補正性格）の値で割った比を順位の基準にしています。

### おてつだいのタイミング

- 表示おてつだい時間 = floor(基準 2300秒 × (1 − (Lv−1) × 0.002) × 性格 × (1 − サブスキル合計))。サブスキル合計の上限は35%、性格は↑0.9倍・↓1.075倍。
- いいキャンプチケット使用時は時間を1.2で割り、最大所持数は ceil(所持数 × 1.2)。
- げんきによる倍率（Ver.1.8.1以降）: 81以上 0.45 / 61〜80 0.52 / 41〜60 0.58 / 1〜40 0.66 / 0 は 1.0。
- げんきは起床時100（げんき回復ボーナス持ちは睡眠回復の上限が105）から、睡眠中も含めて10分ごとに1減る。回復スキルは考えない。
- 次のおてつだいにかかる時間は、ひとつ前のおてつだいが終わった時点のげんきで決まる。起床時の回復は進行中のおてつだいにも反映する。
- タイミングの端数は日をまたいで持ち越すので、捨て日を回したあと8日分を平均する。

### スキル抽選

- スキル確率 = 2.9% × 性格(↑1.2 / ↓0.8) × (1 + スキル確率アップ合計)。
- 連続不発の天井は62回（スキルとくいは基準おてつだい時間で約40時間分 = 144000 / 2300）。
- 日中は常にタップする前提で、ストックは発生しない。
- 睡眠中はスキルとくいなので2回までストックでき、2回たまると抽選が止まる。
- 所持数が満タンになると「いつのまに育成」になり抽選されない。ただし満タンになったおてつだいのあと、キューに残る4回分は抽選される。
- 睡眠中の所持数: きのみ1個（きのみの数Sで2個）、食材おてつだいは1/2/4個のいずれか。食材確率 = 16% × 性格(↑1.2 / ↓0.8) × (1 + 食材確率アップ合計)。

### 上位%の分布

- サブスキルは1枠ごとに色を 金14% / 青33% / 白53% で抽選し、その色の中で未所持のものから均等に選ぶ（重複なし）。
- 性格は25種を等確率とし、↑↓をスキル・おてスピ・食材・その他に分類する。

### 考慮していないもの

- チーム全体のスキル発動回数による確率低下（スキルゲート）。しきい値は非公開で、チーム編成に依存するため。
- フレンドメダルによる1枠目の金確定。

## ローカルで動かす

ES modules を使っているため、`file://` で直接開くのではなく簡易サーバーが必要です。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。
