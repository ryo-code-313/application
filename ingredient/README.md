# 食材タイプ厳選チェッカー

ポケモンスリープの食材タイプ向けの厳選チェッカーです。今はフライゴンに対応しています。狙い食材・食材配列・サブスキル・性格から、狙い食材の1日あたりの期待個数を計算し、無補正個体との比較や全パターン中の順位を表示します。

ミュウツー版（リポジトリ直下）と同じ画面構成で、サブスキル・性格のデータ、げんきとおてつだいのタイミング計算（`js/calc.js` の `schedule`）、サブスキル抽選モデル（`subsetDist`）、スタイルを共有しています。

## 構成

- `index.html` — マークアップ
- `css/theme.css` — 食材タイプ版の配色（レイアウトは `../css/style.css`）
- `js/constants.js` — 食材タイプ版だけで使う定義
- `js/calc.js` — 期待値計算エンジン（DOM非依存）
- `js/worker.js` — 上位%の分布計算をバックグラウンドで実行するWeb Worker
- `js/state.js` — アプリ状態管理・localStorage永続化（キーは `ig` 接頭辞）
- `js/ui.js` — DOM描画・イベント処理
- `js/main.js` — エントリーポイント

## ポケモンのデータ

`js/constants.js` の `MONS` にポケモンごとの基礎値（おてつだい時間・食材確率・最大所持数・食材スロットの候補と個数）を持ちます。ポケモンを増やすときはここに追加します。

| | フライゴン |
|---|---|
| おてつだい時間 | 2700秒 |
| 食材確率 | 17.2% |
| 最大所持数 | 17 |
| Lv.1 | つやつやアボカド×2 |
| Lv.30 | つやつやアボカド×5 / げきからハーブ×6 |
| Lv.60 | つやつやアボカド×7 / げきからハーブ×9 / ワカクサ大豆×12 |

出典: [おがのブログ](https://pokesuri.ogagawa.com/flygon_hyouka/)、[ポケモンスリープ個体値チェッカー](https://www.pokemonsleepdaifuku.com/pokemon/%E3%83%95%E3%83%A9%E3%82%A4%E3%82%B4%E3%83%B3/)

記録はポケモンごとに保存し、今選んでいる狙い食材で並べ替えて表示します。

## 計算モデル

「狙い食材の1日の期待個数」を、無補正個体（サブスキルなし・無補正性格）のうち狙い食材が最も多く取れる食材配列（アボカドなら AAA）の値で割った比を順位の基準にしています。

- おてつだい時間・げんき・いいキャンプチケット・日をまたぐ持ち越しはミュウツー版と同じ（リポジトリ直下の README.md を参照）。
- 食材確率 = 基礎値 × 性格(↑1.2 / ↓0.8) × (1 + 食材確率アップ合計)。
- 食材おてつだいでは、食材配列の3スロット（Lv.1 / Lv.30 / Lv.60）から均等に1つ選び、そのスロットの食材を拾う。
- 日中は常にタップする前提で、所持数はあふれない。
- 睡眠中は所持数0から始まり、きのみ（1個、きのみの数Sで2個）と食材（狙い以外も含む）で埋まっていく。所持数を超えた分は捨てられ、満タン後のおてつだいでは食材は増えない。
- 性格のスキル補正は食材に影響しないので「なし他」として扱う。
- 上位%の分布は、サブスキル（色別抽選・重複なし）と性格25種をミュウツー版と同じモデルで、食材配列は各スロットの候補を等確率として数え上げる。

### 考慮していないもの

- 食材ごとのエネルギー（狙い食材の個数のみで比較）。
- メインスキルの効果、おてつだいボーナスのチーム全体への効果（自分のおてつだい時間の短縮としてのみ計算）。

## ローカルで動かす

リポジトリ直下で簡易サーバーを起動し、`http://localhost:8000/ingredient/` を開いてください。

```bash
python3 -m http.server 8000
```
