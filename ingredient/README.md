# 食材タイプ厳選チェッカー

ポケモンスリープの食材タイプ向けの厳選チェッカーです。ポケモンごとの基礎値を入力し、選んだサブスキル・性格から1日あたりの期待食材個数を計算して、無補正個体との比較や全パターン中の順位を表示します。

ミュウツー版（リポジトリ直下）と同じ画面構成で、サブスキル・性格のデータ、げんきとおてつだいのタイミング計算（`js/calc.js` の `schedule`）、サブスキル抽選モデル（`subsetDist`）、スタイルを共有しています。

## 構成

- `index.html` — マークアップ
- `css/theme.css` — 食材タイプ版の配色（レイアウトは `../css/style.css`）
- `js/constants.js` — 食材タイプ版だけで使う定義
- `js/calc.js` — 期待値計算エンジン（DOM非依存）
- `js/worker.js` — 上位%の分布計算をバックグラウンドで実行するWeb Worker
- `js/state.js` — アプリ状態管理・localStorage永続化（キーは `ig` 接頭辞）
- `js/ui.js` — DOM描画・イベント処理
- `js/main.js` — エントリーポイント

## 入力する基礎値

- おてつだい時間（「分:秒」または秒数）
- 食材確率（%）
- 最大所持数
- Lv.1 / Lv.30 / Lv.60 の食材スロットで拾う個数

記録は基礎値ごとに分けて保存・表示します。

## 計算モデル

「1日の期待食材個数」を、無補正個体（サブスキルなし・無補正性格）の値で割った比を順位の基準にしています。

- おてつだい時間・げんき・いいキャンプチケット・日をまたぐ持ち越しはミュウツー版と同じ（リポジトリ直下の README.md を参照）。
- 食材確率 = 基礎値 × 性格(↑1.2 / ↓0.8) × (1 + 食材確率アップ合計)。
- 食材おてつだいでは、解放済みの3スロットから均等に1つ選び、そのスロットの個数を拾う。
- 日中は常にタップする前提で、所持数はあふれない。
- 睡眠中は所持数0から始まり、きのみ（1個、きのみの数Sで2個）と食材で埋まっていく。所持数を超えた分は捨てられ、満タン後のおてつだいでは食材は増えない。
- 性格のスキル補正は食材に影響しないので「なし他」として扱う。
- 上位%の分布は、サブスキル（色別抽選・重複なし）と性格25種をミュウツー版と同じモデルで数え上げる。

### 考慮していないもの

- 食材ごとのエネルギー（個数のみで比較）。
- メインスキルの効果、おてつだいボーナスのチーム全体への効果（自分のおてつだい時間の短縮としてのみ計算）。

## ローカルで動かす

リポジトリ直下で簡易サーバーを起動し、`http://localhost:8000/ingredient/` を開いてください。

```bash
python3 -m http.server 8000
```
