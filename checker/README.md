# 厳選チェッカー（食材タイプ・きのみタイプ）

ポケモンスリープの食材タイプ（最終進化形40匹）ときのみタイプ（最終進化形31匹）向けの厳選チェッカーです。画面上部のタブできのみタイプと食材タイプを切り替えます。

- 食材タイプ: 狙い食材・食材配列・サブスキル・性格から、狙い食材の1日あたりの期待個数を計算します。
- きのみタイプ: サブスキル・性格から、1日あたりのきのみエナジーの期待値を計算します。

どちらも無補正個体との比較や全パターン中の順位を表示します。ミュウツー版（リポジトリ直下）と同じ画面構成で、サブスキル・性格のデータ、げんきとおてつだいのタイミング計算（`js/calc.js` の `schedule`）、サブスキル抽選モデル（`subsetDist`）、スタイルを共有しています。

## 使い方

- 画面上部のタブでタイプを選び、その下の欄でポケモンを選びます。`?mon=flygon` のように URL でも指定でき、タブもそのポケモンのタイプになります。
- タブを切り替えると、そのタイプで前回選んだポケモンに戻ります。選んだポケモンと、食材タイプの狙い食材は次に開いたときにも使います。
- ポケモンやタイプを切り替えても、サブスキルと性格はそのまま残ります。食材配列は選び直しになります。
- 幅の広い画面では、入力を左、結果を右の2列に並べます。
- 記録はポケモンごとに表示します。統合前の食材タイプ版・きのみタイプ版の記録もそのまま表示されます。
- 以前の URL（`../ingredient/`・`../berry/`）は、ポケモンの指定を引き継いでこのページに移動します。

## 構成

- `index.html` — マークアップ
- `css/theme.css` — 配色（食材タイプは緑、きのみタイプは青。レイアウトは `../css/style.css`）
- `js/types.js` — 食材タイプ・きのみタイプの定義をまとめる
- `js/state.js` — アプリ状態管理・localStorage永続化（記録は統合前と同じ `iglog`・`bflog`、共通の設定は `ck` 接頭辞）
- `js/ui.js` — DOM描画・イベント処理
- `js/worker.js` — 上位%の分布計算をバックグラウンドで実行するWeb Worker
- `js/main.js` — エントリーポイント
- `js/ingredient/` — 食材タイプの定義（`constants.js`）・期待値計算エンジン（`calc.js`、DOM非依存）・ポケモンの基礎値（`mons.js`）
- `js/berry/` — きのみタイプの定義・期待値計算エンジン・ポケモンの基礎値

### 計算モデル

「狙い食材の1日の期待個数」を、無補正個体（サブスキルなし・無補正性格）のうち狙い食材が最も多く取れる食材配列（フライゴンのアボカドなら AAA）の値で割った比を順位の基準にしています。

- おてつだい時間・げんき・いいキャンプチケット・日をまたぐ持ち越しはミュウツー版と同じ（リポジトリ直下の README.md を参照）。
- 食材確率 = 基礎値 × 性格(↑1.2 / ↓0.8) × (1 + 食材確率アップ合計)。
- 食材おてつだいでは、食材配列の3スロット（Lv.1 / Lv.30 / Lv.60）から均等に1つ選び、そのスロットの食材を拾う。
- 日中は常にタップする前提で、所持数はあふれない。
- 睡眠中は所持数0から始まり、きのみ（1個、きのみの数Sで2個）と食材（狙い以外も含む）で埋まっていく。所持数を超えた分は捨てられ、満タン後のおてつだいでは食材は増えない。
- 性格のスキル補正は食材に影響しないので「なし他」として扱う。
- 上位%の分布は、サブスキル（色別抽選・重複なし）と性格25種をミュウツー版と同じモデルで、食材配列は各スロットの候補を等確率として数え上げる。

#### 考慮していないもの

- 食材ごとのエネルギー（狙い食材の個数のみで比較）。
- メインスキルの効果、おてつだいボーナスのチーム全体への効果（自分のおてつだい時間の短縮としてのみ計算）。

### 計算モデル

「きのみの1日の期待エナジー」を、無補正個体（サブスキルなし・無補正性格）の値で割った比を順位の基準にしています。

- おてつだい時間・げんき・いいキャンプチケット・日をまたぐ持ち越しはミュウツー版と同じ（リポジトリ直下の README.md を参照）。
- きのみ1個のエナジー = max(基礎 + Lv − 1, round(基礎 × 1.025^(Lv − 1)))。Lv.60（3枠）/ Lv.70（4枠）で計算する。
- きのみおてつだい1回で拾うきのみは、きのみタイプの2個（きのみの数Sで3個）。
- 起床時に所持品を受け取り、日中はタップしない（いつのまに育成）。起床から次の起床までを所持数0から続けて追う。
- 満タンになるまでは、食材確率 = 基礎値 × 性格(↑1.2 / ↓0.8) × (1 + 食材確率アップ合計) で食材おてつだいになり、それ以外はきのみおてつだい。食材おてつだいでは食材配列の3スロット（Lv.1 / Lv.30 / Lv.60）から均等に1つ選び、そのスロットの個数を拾う。
- 満タンになった後は、食材確率に関係なくすべてのおてつだいできのみ（きのみの数Sの効果込み）を拾い、所持数からあふれたきのみはエナジーになる（いつのまに育成）。満タンになったおてつだいであふれた食材は捨てられる。おてつだいキューに残った最大4回分はメインスキルの抽選にだけ使われ、拾うものはきのみになる。
- そのため、1日のきのみ = 1回あたりのきのみ × (おてつだい回数 − 満タンになる前の食材おてつだい回数)。食材確率は満タンになるまでの数回にしか効かず、所持数を増やすと満タンが遅れて食材おてつだいが増えるぶん、きのみのエナジーはわずかに減る。
- 食材配列は入力しない。各スロットの候補を等確率として、配列ごとの値を出現確率で平均する（たとえばトドゼルガは Lv.60 の候補がすべて4個なので、Lv.30 がオイル×2 かマメミート×3 かだけが効く）。
- 性格のスキル補正はきのみに影響しないので「なし他」として扱う。
- 上位%の分布は、サブスキル（色別抽選・重複なし）と性格25種をミュウツー版と同じモデルで数え上げる。

#### 考慮していないもの

- 食材とメインスキルによるエナジー（きのみのエナジーのみで比較）。満タンの間はスキルも抽選されない。
- 日曜夜から月曜朝にかけては満タン後にいつのまに育成へ移行しない（週の最終日だけの例外なので、毎日同じとして計算）。
- イベントボーナスの「通常のおてつだいで拾うきのみ+1」（いつのまに育成では効かない）。
- おてつだいボーナスのチーム全体への効果（自分のおてつだい時間の短縮としてのみ計算）。
- 性格のげんき回復量補正（ミュウツー版・食材タイプ版と同じく、起床時のげんきは補正なしで計算）。
