# きのみタイプ厳選チェッカー

ポケモンスリープのきのみタイプ向けの厳選チェッカーです。今はトドゼルガに対応しています。サブスキル・性格から、1日あたりのきのみの期待個数を計算し、無補正個体との比較や全パターン中の順位を表示します。

ミュウツー版（リポジトリ直下）・食材タイプ版（`ingredient/`）と同じ画面構成で、サブスキル・性格のデータ、げんきとおてつだいのタイミング計算（`js/calc.js` の `schedule`）、サブスキル抽選モデル（`subsetDist`）、スタイルを共有しています。

## 構成

- `index.html` — マークアップ
- `css/theme.css` — きのみタイプ版の配色（レイアウトは `../css/style.css`）
- `js/constants.js` — きのみタイプ版だけで使う定義
- `js/calc.js` — 期待値計算エンジン（DOM非依存）
- `js/worker.js` — 上位%の分布計算をバックグラウンドで実行するWeb Worker
- `js/state.js` — アプリ状態管理・localStorage永続化（キーは `bf` 接頭辞）
- `js/ui.js` — DOM描画・イベント処理
- `js/main.js` — エントリーポイント

## ポケモンのデータ

`js/constants.js` の `MONS` にポケモンごとの基礎値（おてつだい時間・食材確率・最大所持数・1回あたりのきのみの個数・食材スロットの候補と個数）を持ちます。ポケモンを増やすときはここに追加します。

| | トドゼルガ |
|---|---|
| きのみ | チーゴのみ×2 |
| おてつだい時間 | 3000秒 |
| 食材確率 | 22.3% |
| 最大所持数 | 18 |
| Lv.1 | ピュアなオイル×1 |
| Lv.30 | ピュアなオイル×2 / マメミート×3 |
| Lv.60 | ピュアなオイル×4 / マメミート×4 / あったかジンジャー×4 |

出典: [RaenonX ポケスリ攻略ツール](https://pks.raenonx.cc/ja/pokedex/365)（食材確率は71件の集計値）、[ポケモンスリープ個体値チェッカー](https://www.pokemonsleepdaifuku.com/pokemon/%E3%83%88%E3%83%89%E3%82%BC%E3%83%AB%E3%82%AC/)（食材確率は参考値22.40%）、[Serebii](https://www.serebii.net/pokemonsleep/pokemon/walrein.shtml)

## 計算モデル

「きのみの1日の期待個数」を、無補正個体（サブスキルなし・無補正性格）の値で割った比を順位の基準にしています。きのみ1個のエナジーは同じレベルなら補正に関係なく同じなので、比を取ると消えます。

- おてつだい時間・げんき・いいキャンプチケット・日をまたぐ持ち越しはミュウツー版と同じ（リポジトリ直下の README.md を参照）。
- 食材確率 = 基礎値 × 性格(↑1.2 / ↓0.8) × (1 + 食材確率アップ合計)。食材おてつだい以外はきのみおてつだいになるので、食材確率が上がるときのみは減る。
- きのみおてつだい1回で拾うきのみは、きのみタイプの2個（きのみの数Sで3個）。
- 日中は常にタップする前提で、所持数はあふれない。
- 睡眠中は所持数0から始まり、きのみと食材で埋まっていく。食材おてつだいでは食材配列の3スロット（Lv.1 / Lv.30 / Lv.60）から均等に1つ選び、そのスロットの個数を拾う。所持数を超えた分は捨てられ、満タン後のおてつだいでは何も増えない。
- 食材配列は入力しない。各スロットの候補を等確率として、配列ごとの値を出現確率で平均する（トドゼルガは Lv.60 の候補がすべて4個なので、Lv.30 がオイル×2 かマメミート×3 かだけが効く）。
- 性格のスキル補正はきのみに影響しないので「なし他」として扱う。
- 上位%の分布は、サブスキル（色別抽選・重複なし）と性格25種をミュウツー版と同じモデルで数え上げる。

### 考慮していないもの

- 食材とメインスキルによるエナジー（きのみの個数のみで比較）。
- おてつだいボーナスのチーム全体への効果（自分のおてつだい時間の短縮としてのみ計算）。
- 性格のげんき回復量補正（ミュウツー版・食材タイプ版と同じく、起床時のげんきは補正なしで計算）。

## ローカルで動かす

リポジトリ直下で簡易サーバーを起動し、`http://localhost:8000/berry/` を開いてください。

```bash
python3 -m http.server 8000
```
